## Things a re-run should know

**The suite is environment-sensitive.** `tests/test_config.py::TestConfig::
test_get_configured_features` asserts that no optional feature is configured,
but `Config` reads `GITHUB_TOKEN` from the environment. On any machine that
exports `GITHUB_TOKEN` or `GH_TOKEN` — many CI containers and dev shells do —
that test fails for reasons unrelated to this repository. Clear the variables
to reproduce a clean run:

```bash
env -u GITHUB_TOKEN -u GH_TOKEN pytest -q
```

This is an upstream test-isolation gap, not a fork modification, and belongs
upstream.

**`README.md` is covered by upstream's documentation-policy tests.**
`tests/test_auth_guidance_policy.py` asserts that the root `README.md` states
the Twitter environment-variable boundary (`TWITTER_AUTH_TOKEN`,
`TWITTER_CT0`) and the current Bilibili and Xiaohongshu backend routes. Because
this fork replaces the README, edits to it can break those tests even though no
upstream source changed. Re-run the suite after any README change.
